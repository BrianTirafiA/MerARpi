# Capstone F-08: MerARpi 🌋
An augmented reality-based educational media application for Taman Nasional Gunung Merapi (Mount Merapi National Park), developed as a Capstone project. This application is built using the Unity Engine and Vuforia Engine.

## 📖 About The Project
This project aims to enhance the educational experience for visitors of Taman Nasional Gunung Merapi by providing an interactive AR application. Users can bring educational content to life by scanning designated markers, offering a more engaging and immersive way to learn about the geology, flora, and fauna of the Mount Merapi ecosystem.

## ✨ Features
The application supports two distinct types of AR markers:

🃏 Card Markers: Users can scan flat image markers, such as those on informational cards or brochures. When a card is scanned, a corresponding 3D model or animation will appear augmented onto the card, along with descriptive text.

🏰 Maquette Markers: The app can also recognize and augment content onto a physical 3D model (maquette) of Mount Merapi. This allows for a more dynamic and spatially aware presentation of information, showing different zones, historical eruption paths, and points of interest directly on the model.

## 🛠️ Technology Stack
This project is made possible by the following technologies:

Unity Engine: The core 3D development platform used to build the application.

Vuforia Engine: A powerful SDK for augmented reality that enables the image and object tracking functionalities.
